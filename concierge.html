Before your Job Agent starts

Confirm four items once. You can pause the agent and revoke this authorization at any time.

What this enables

Direct-employer job discovery, encrypted storage of facts you confirm, AI-assisted document preparation, and a supervised application workspace.

It never authorizes final submission or personal-data transmission. Those consequential steps still require a separate action-time confirmation.

No date of birth, employer password, OTP, or CAPTCHA answer is requested or stored here.

Guided campaign creation

Build the operating contract

Configuration may persist. Do not enter PII, resumes, credentials, private prompts, or account data.

1. Campaign type and objective

Start from a reusable template or define another operational outcome.

2. Schedule and cadence

Describe when an integrated runner would execute. Saving this does not create a scheduler.

Integration Required: the preview stores this intent but will not run in the background.

3. Targets and priorities

Set measurable run targets. Blank values remain unknown rather than becoming fabricated counts.

4. Hard rules and exclusions

Rules are mandatory. Exclusions say what the campaign must never include.

5. Standing authorization

Define the reversible work the agent may do automatically inside this campaign’s scope.

Standing authorization never covers credentials, OTP/CAPTCHA, material consent, signatures, payments, or new private facts.

6. Human-action triggers

One blocked item pauses only that item. The rest of the queue may continue safely.

7. Evidence and reporting

Define what proves completion and what every report must disclose.

8. Stop conditions

A persistent campaign needs an explicit definition of done and safe exit conditions.

Advanced mode
The saved campaign remains in Design mode until a real scheduler and execution integration are separately connected and verified.
