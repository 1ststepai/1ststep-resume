# 2026-09-18 — Short search-first onboarding

## Changed

- Goal, job type, and salary stay available under optional filters on the last screen, with Full-time / any salary / best-fit defaults.

## Why
- First-run setup had seven required taps before search. Only resume, path, and location are needed to start looking for jobs.
