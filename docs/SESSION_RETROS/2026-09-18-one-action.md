# 2026-09-18 — One next action after search

## Changed
- Zero-match search now has one action: Try a different job type, which opens the job-path picker.
- Matches keep one action: Review my jobs.
- Status header shows only that same next action. Chat prompts no longer offer a second choice.

## Why
- Testers were given three buttons after a search and got an off-topic reply from Review my current mission.
