# 2026-09-18 — Auto-prepare drafts after search

## Changed
- After a search finds jobs, the agent now verifies the listing when the apply path is already confirmed and starts private résumé drafts.
- Testers are asked to review those drafts. Nothing is sent to an employer.
- Jobs no longer sit on Prepare application until someone clicks each card.

## Why
- My Jobs showed Saved match cards that still asked the user to confirm the listing and prepare materials, even though the search had already done the safe work.
