# 2026-09-18 — Search results lead with a next step

## Changed
- After a job search, the conversation shows the outcome and one next action instead of screening counts.
- Zero matches ask the user to try a different type of job. Matches ask the user to open My Jobs.
- Status copy no longer says “Finished with partial results.”

## Why
- Testers saw 10,000-listing screening jargon after search. That work should stay in the background.
