# 2026-09-18 — Two-tester beta runs the full in-scope loop

## Changed
- After search, the agent verifies listings, starts résumé drafts, and opens the first draft for review.
- Saving a résumé also selects it as the application base so drafts can start without extra Saved Info clicks.
- Job cards no longer ask testers to Continue application when employer fill is not part of this invite.

## Why
- Two testers should feel the full product through review. Employer fill and submit stay off because the served Terms do not include them.
